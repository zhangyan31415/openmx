# 从输入启用 CPU 对称性

使用统一 CPU 构建的 `openmx-cpu`，在普通输入中加入：

```text
scf.Symmetry on
```

默认是 `off`；省略这一行保持普通输入的行为。NSOC 和随后的 SOC 输入应使用相同设置。

```bash
mpirun -np 64 /path/to/build/openmx-cpu input.dat -nt 1
```

不需要用户预先执行元数据准备命令、编写 JSON 请求或填写求解器环境变量。程序在初始化阶段调用配套 Python 工具，识别可用的闭合对称子群、验证原子与周期邻居映射、生成标量或自旋表示，并分发给 MPI 进程。应保留构建时使用的 Python 环境和 NumPy、SciPy、spglib，以及与二进制匹配的配套工具。

开启后同时启用已验证且兼容的内存与求解优化。C3/D3 在支持的标准定向层状几何下自动使用专用 SOC 路径；其他受支持情况走通用路径。线程数、绑核、混合方式及用户 History 决定某些缓存／压缩是否适用，程序不会为打开优化而改写这些输入。最新同节点前后对比见[基准报告](benchmarks/20261106/README.md)。

## 行为

初始化时，主日志由 MPI rank 0 输出实际采用的子群、检测点群、操作数量、最大几何残差，以及每个操作的分数坐标旋转矩阵 `W`、平移 `t_frac` 和笛卡尔旋转矩阵 `R_cart`。分数坐标采用列向量约定 `x' = W x + t`。NSOC 和 SOC 各输出一次；完整原子置换和周期 image 映射保存在日志所指准备目录的 `metadata/selected.symmetry.json`。

程序不会将受支持子群冒称为完整晶体点群。无法完成映射、表示构造或真正的算子正确性检查时明确停止，不打印“启用成功”后忽略请求。

对称性贯穿受支持 NSOC 路径的 SCF 计算，不只在前若干步使用。保留用户指定的基组、截断、电子温度、SCF 精度和混合历史长度。通过对称性约束的收敛与完全不约束的收敛并非同一个数值问题，需分别报告残差及物理差异。

当输入还指定普通 `HS.fileout on` 时，导出的 H/S 与所采用的群投影一致。SOC 使用轨道与自旋表示，并检查求解算子和导出算子是否一致。导出钩子不改写 DM。OpenMX 基组非正交，后处理仍须使用这次计算匹配的 S，不能替换成单位阵。

## 范围和精度

当前验证范围为固定几何、非磁性、Gamma 点：完整 NSOC 收敛后接自身检查点的一步 SOC。不同群、材料和角度的支持及性能以实际验收为准；识别成功不表示任意材料都获得加速或通过物理误差标准。当前不宣称任意 k 点、磁性、几何优化和多步 SOC 已认证。

几何容差、电子算子协变残差与最终能量／力误差是三个不同检查。通用 SOC 在显式对称化时，将原始 H/S 的空间协变与实规范破缺作为投影大小的诊断，不因其超过原始协变门限直接退出。求解验收改为针对实际对称化后的 H/S，检查抽样本征对残差和 S 正交性，门限仍为 `1e-8`；原始残差也保留输出。未对称化求解仍要求原始协变检查通过。

非有限数、非磁时间反演、厄米性、几何映射、基变换以及求解与导出算子一致性仍受检查。有限网格可破坏空间旋转对称性，但不能解释所有异常。不能把放宽几何识别解释为允许同样大的物理误差。与未对称参考的物理精度比较应独立保留，见[验收说明](ACCEPTANCE.zh-CN.md)。

本次通用 SOC 检查与启动输出的实际验证见[测试记录](PROJECTED_SOC_VALIDATION_20261106.md)。

## 运行生命周期

程序没有内部计算倒计时；调度器分区或 allocation 的外部期限仍由调度器执行。普通 MPI 任务的持久性由启动它的批作业或会话决定，无限内部时限不等于关闭终端后仍会继续。

两步输入和检查点要求见[运行及重启](WORKFLOW.zh-CN.md)，安装依赖见[构建说明](BUILD.zh-CN.md)。
