# 原生对称性开关验证（2026-11-06）

本轮验证 `scf.Symmetry on/off` 与普通 MPI 启动的接入，不是性能基准。
用户无需先执行准备命令或编写元数据。高级控制仍保留在实现中。

## 构建与回归

统一 CPU 目标从仓库源码构建，共311个翻译单元；最终输入适配器增量重编译。
构建节点 gpuh204，Intel oneAPI2022.3（MPI2021.7.1、MKL2022.2.1），
Python3.12.7及NumPy、SciPy、spglib。无外部OpenMX对象文件。

最终二进制SHA256：
`ac57ac3da1f7165be856f5d954c17cec95fe2c48e0f05150181ae4d1cdb62bb0`。
192项回归测试通过。原生输入的SOC与H/S输出逻辑值兼容上游全部拼写。
构建清单记录了静态源码和配套工具的校验和，验收时核对一致。

## 三原子原生集成测试

采用既有HgI₂三原子夹具，保留I7.0-s3p2d2、Hg8.0-s3p2d2、150Ry、300K、
SCF阈值1e-7、History35及StartPulay15。每套完整流程从自身NSOC检查点启动SOC。

| 检查 | 布局／节点 | 结果 |
|---|---|---|
| 显式关闭；清除继承的优化配置；缺失准备工具不影响关闭路径 | gpuh204，4MPI×1 | NSOC及一步SOC通过 |
| 直接开启；内部识别D2；清除继承的其他群配置 | gpuh204，4MPI×1 | NSOC及一步SOC通过 |
| 双节点直接开启 | gpuh202、gpuh204，各2MPI×1 | NSOC及一步SOC通过 |
| 二进制与配套工具整体搬到含空格的路径 | gpuh204，4MPI×1 | NSOC及一步SOC通过 |
| 不请求H/S文件 | gpuh204，4MPI×1 | 一步SOC通过，无scfout输出 |
| 原生逻辑值别名，分别开启和关闭H/S输出 | gpuh204，4MPI×1 | 两次一步SOC通过 |
| 开启时故意指定不存在的准备工具 | gpuh204，4MPI×1 | 全体MPI进程按预期拒绝，退出码95 |

共11个正向原生阶段通过。启用的每个阶段只执行一次准备，关闭时不调用Python。
单／双节点、整体搬移、以及此前相同投影算子的准备路径之间，完整周期H/S/DM、
能量、力、电子数及厄米性检查通过。scfout不含完整EDM，不能由此宣称完成EDM逐元素检查。

开关对照最大力差：NSOC约6.69e-6meV/Å，SOC约1.85e-5meV/Å；
SOC总能量差约4.01e-12Ha。该夹具通过0.1meV/atom和1meV/Å物理门限，
不代表其他材料的误差。

## 大角度材料检查与限制

MoTe₂9.43°，222原子、3848标量AO，gpuh203，32MPI×1。
直接开启后NSOC完成39步并正常退出。自身检查点的一步SOC在默认协变检查处拒绝：
原始H相对协变残差约4.65749e-4，超过默认1e-5；S约4.58074e-7。
程序未放宽阈值，也未静默切换为其他路径。

因此，本轮不能把这例列为NSOC加SOC全流程成功，不能把历史D3专用SOC最快记录
当作当前直接开启入口的性能。当前接口已接通，通用SOC的实际适用性仍受算子检查限制。

完整私有复现实验按`openmx_symmetry_switch_20261106`归档，包含输入、命令、
环境、节点、布局、准备清单、正常／失败日志和逐块比较结果；不随源码发布计算数据。
